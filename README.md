# Hardened Linux Server + Monitoring Dashboard with LVM Storage

This project is for learning Linux system administration on an Ubuntu Server 22.04 VM.

## Modules

1. SSH hardening
2. UFW firewall
3. fail2ban
4. LVM storage
5. Monitoring stack
6. Documentation

## Module 1 Files

- `ssh/sshd_config_changes.md`: explains SSH hardening concepts, the exact configuration change.

## Goal

Build a secure server while understanding why each command matters.
